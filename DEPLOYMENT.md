# Deploying The Cafeteria (Vercel + Render + MongoDB Atlas)

The app has two parts that deploy separately:
- **Frontend** (React) → Vercel
- **Backend** (FastAPI + MongoDB) → Render (free tier) with MongoDB Atlas (free tier)

Total cost: **₹0** on free tiers.

---

## Step 1 — Push to GitHub
In Emergent: profile icon → connect GitHub → project menu → **Save to GitHub** → name it `the-cafeteria` (private is fine).

## Step 2 — MongoDB Atlas (database)
1. Go to [cloud.mongodb.com](https://cloud.mongodb.com) → create free account → **Build a Database** → M0 Free → region `Mumbai` → name it `cafeteria`.
2. Create a database user (username + password — save these).
3. Network Access → **Allow Access from Anywhere** (`0.0.0.0/0`).
4. Connect → Drivers → copy the connection string, e.g.
   `mongodb+srv://<user>:<password>@cluster0.xxxx.mongodb.net/?retryWrites=true&w=majority`

## Step 3 — Backend on Render
1. Go to [render.com](https://render.com) → sign up with GitHub → **New → Blueprint** → select the `the-cafeteria` repo (the included `render.yaml` configures everything).
2. When prompted, fill the secret env vars:
   - `MONGO_URL` → your Atlas connection string from Step 2
   - `ADMIN_PASSWORD` → your admin panel password
   - `CORS_ORIGINS` → leave as `*` for now; tighten after Step 4
   - `EMERGENT_LLM_KEY` → your Emergent universal key (for AI dish photos)
   - `JWT_SECRET` → auto-generated by the blueprint
3. Deploy. Render gives you a URL like `https://cafeteria-api.onrender.com`.
4. Test it: open `https://cafeteria-api.onrender.com/api/` — you should see `{"message":"The Cafeteria API"}`. The menu auto-seeds on first run.

> Free Render services sleep after 15 min idle — first request after sleep takes ~30s. Upgrade ($7/mo) to keep it always-on.

## Step 4 — Frontend on Vercel
1. Go to [vercel.com](https://vercel.com) → sign up with GitHub → **Add New → Project** → import `the-cafeteria`.
2. Set **Root Directory** to `frontend` (the included `vercel.json` handles the rest).
3. Add environment variable:
   - `REACT_APP_BACKEND_URL` → `https://cafeteria-api.onrender.com` (your Render URL, no trailing slash, no /api)
4. Deploy. You get `https://the-cafeteria.vercel.app`.
5. Back in Render, set `CORS_ORIGINS` to your Vercel URL for tighter security.

## Step 5 — Your own domain (optional, for the final QR code)
1. Buy a domain (e.g. `thecafeteria.in` on GoDaddy/Hostinger/Namecheap, ~₹500–900/yr).
2. Vercel → Project → Settings → Domains → add your domain → follow the DNS instructions it shows (usually one CNAME record at your registrar).
3. Done — the QR code and printable poster **automatically** use whatever domain the site is opened on. Reprint table posters after the domain is live.

## After going live checklist
- [ ] Login at `/admin` on the new domain works
- [ ] Place a test order — appears in admin Orders + WhatsApp opens
- [ ] Scan the QR code with a phone — opens the new domain
- [ ] Generate one AI dish photo — confirms the LLM key works
- [ ] Re-add "Today's Specials" (the new database starts with the original seeded menu; edits/orders/AI photos from the preview stay on the preview database)
